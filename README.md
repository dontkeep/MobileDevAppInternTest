## About

This project is designed to showcase my mobile development skills by integrating modern Android libraries and tools. The application demonstrates network communication with retrofit2 and okhttp, image loading using glide, animations with lottie animation by airbnb, and custom UI components.

## Technologies Used

- **Retrofit2**: For handling API requests and network communication.
- **OkHttp**: For efficient HTTP client operations and logging.
- **Lottie**: For rendering smooth and high-quality animations.
- **Glide**: For fast and efficient image loading and caching.
- **CircleImageView**: For displaying circular images within the UI.
